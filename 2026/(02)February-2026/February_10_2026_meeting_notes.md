## Main Discussion: Paul Trapani - Obsidian editor/markup managment system
*[Obsidian](https://obsidian.md)*: a note-taking app
- Licensing: Source-available but there is a custom license and access to beta features can be obtained earlier by buying commerical or "Catalyst" licensing.
    - Since the content is written in Markdown there is no vendor lock-in.


- PKM: Personal Knowledge Management
    - An early example of PKM is [HyperCard](https://en.wikipedia.org/wiki/HyperCard)

### Obsidian Features
- Cross Platform
- Local Storage (can be synced to cloud of course using something like [Nextcloud](https://nextcloud.com))
    - Alternatively Obsidian has their own cloud sync called [Obsidian Sync](https://obsidian.md/sync).
    - Git is possible
- Obsidian app has different folders and split screen
- Stylize the notes using [Markdown conventions](https://www.markdownguide.org/basic-syntax/).
    - Menus can help with formatting
- Custom hot-keys and shortcuts
- Config and documents are stored in a folder called a [Vault](https://help.obsidian.md/vault). These folders can be sent to different computers.
- Images and metadata can be attached
- Coding is supported but it is not a strong IDE; it is better for viewing code or embedding snippets into documentation for display
    
- *Obsidian Bases*: Can make database of documents to scroll through
- Automatic Saves
- Command palate
- *Graph View* can show related notes
- Publish features which can push files to remote sources

#### Plugins for additional features:
- [Note Refactor](https://github.com/lynchjames/note-refactor-obsidian): Highlight text in one note and send it to a new note.
    - Can make first line the title of the note.
    - Export to PDF is built-in or added with an add-in called [Pandoc](https://github.com/OliverBalfour/obsidian-pandoc).
